# Camp artwork

Drop image files here and reference them from **/admin/content → Fresh Fire cards**
as a site-relative path, e.g.

    /camp/fresh-fire-01.jpg

Anything in `public/` is served from the site root, so no import or config is needed.

Recommended: portrait, roughly 3:4 (e.g. 1200×1600), JPG or WebP, under ~400 KB each.
A card with no image falls back to an ember gradient, so the carousel always looks finished.
